# CodeSquad Test Repository

A small HTML and CSS practice project for CodeSquad. This repository is public so the assignment can be reviewed.

## Files

- `index.html` — the page structure and content
- `style.css` — the page colors, spacing, and layout
- `README.md` — this project overview

## View the page

Download or clone the repository, then open `index.html` in a web browser. No installation or build step is needed.

## Practice focus

Semantic HTML, an external stylesheet, and the basics of keeping project files together on GitHub.
